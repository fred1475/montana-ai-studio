# Montana AI Studio

Plataforma creativa pública e independiente de **Montana Music Production LLC**.

## Estado
Primera versión beta del sitio, en `index.html`. Esta versión ofrece una **herramienta gratuita de preparación de briefs creativos** que funciona localmente en el navegador. No se presenta como generador de IA: la integración con modelos se incorporará en una etapa posterior.

## Planes
- **Free**: herramienta de planificación creativa, sin registro ni tarjeta.
- **Premium**: funciones avanzadas previstas; **aún no disponible para contratación, sin precios confirmados**.
- **Creator Pro**: en evaluación.

## Privacidad
Este repositorio es público. **No publicar en él canciones inéditas, letras propias, prompts exclusivos, fotografías personales, claves, credenciales, datos de clientes, documentos privados ni estrategias internas.** Guardar las claves de futuras integraciones únicamente como secretos en infraestructura backend privada, nunca en HTML o JavaScript públicos.

## Publicación
El repositorio tiene un sitio estático listo para configurar con GitHub Pages (rama `main`, carpeta `/root`). La mera existencia de `index.html` **no certifica que GitHub Pages ya esté habilitado**.
